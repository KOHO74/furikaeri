# 🎮 Python 数当てミニゲーム (High & Low)

Pythonで動く、シンプルでスピーディーな数当てゲームです。
1分程度のちょっとしたスキマ時間の息抜きにどうぞ！

---

## 🕹️ ゲームのルール

1. コンピュータが **1 〜 100** の中からランダムに数字を1つ決めます。
2. プレイヤーは数字を予想して入力します。
3. 入力した数字に対して、コンピュータがヒントをくれます。
   - `⬆️ もっと【大きい】よ！`
   - `⬇️ もっと【小さい】よ！`
4. **6回以内**にピタリと当てられたらあなたの勝ちです！
